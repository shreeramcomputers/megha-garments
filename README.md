# Megha Garments — Website Demo

Static responsive business website for Megha Garments, 213 Ganj Mandi, Sardhana, Meerut.

## Preview
Once GitHub Pages deployment is enabled and successful: https://shreeramcomputers.github.io/megha-garments/

## Before using for the real business
- Confirm the business name, address and exact entrance with the owner.
- Add a verified public phone number and opening hours if the owner approves.
- Replace sample remote photos with approved business/product photos.
- Confirm clothing categories and all public claims.
- This is an informational demo, not an online store; it does not accept orders or payments.
